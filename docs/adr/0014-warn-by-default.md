# Enforcing a rule: warn by default, refuse only where Xavier has said so

Decided: 2026-09-28.

When the app enforces a limit, it warns by default and lets the GM carry
on. It refuses outright only where Xavier has decided so. Refusals so far:
- Seize the Initiative before rolling.
- Giving a turn to someone who hasn't rolled (they are skipped).
- Placing a file anywhere but a commlink, deck or host.

The PAN slave cap warns (see [the slave cap](0011-slave-cap-warns.md)).
